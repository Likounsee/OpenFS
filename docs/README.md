# Documentation OpenFS

Cette documentation explique le projet sans supposer que le lecteur connaît déjà son code.

## Par où commencer ?

1. [Présentation et première utilisation](GETTING_STARTED.md) — compiler OpenFS et créer une image de test.
2. [Architecture](ARCHITECTURE.md) — comprendre les composants et leur rôle.
3. [Format disque](DISK_FORMAT.md) — comprendre comment les données sont organisées.
4. [Pilote Windows](WINDOWS_DRIVER.md) — distinguer le montage Dokany du futur pilote natif.
5. [Sécurité et limites](SAFETY.md) — savoir ce qui est sûr, expérimental ou non implémenté.
6. [Feuille de route](ROADMAP.md) — voir ce qu'il reste à construire.
7. [Vision des versions](VERSIONS.md) — distinguer OpenFS Basic (objectif exFAT) et OpenFS complet.

La documentation décrit l'état du code, pas une promesse de fonctionnalités futures. Lorsqu'une fonction n'est pas réellement utilisable, cela est indiqué explicitement.
